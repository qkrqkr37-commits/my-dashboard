# MY · COMMAND BOARD

다크 글래스 톤의 개인 대시보드 — 오늘의 루틴·할 일, 달력·시간·날씨 히어로, 경제 모닝 브리핑, 포트폴리오 도넛, 가계부까지 한 화면에 담은 **단일 HTML 파일**입니다.

- 빌드 도구나 서버가 필요 없습니다. `index.html` 하나로 동작합니다.
- 금액·종목·일정은 모두 **예시 데이터**이며, 브라우저를 열 때마다 "오늘"을 기준으로 새로 만들어집니다.
- 기록은 서버로 전송되지 않고 브라우저 `localStorage`에만 저장됩니다.
- 우측 상단 `⋯` 메뉴에서 **JSON으로 백업 / 백업 불러오기 / 예시 데이터로 초기화**를 쓸 수 있습니다. 다른 기기에서 쓰던 기록은 백업 파일을 불러와 그 브라우저에 복원할 수 있습니다.

## 보기

GitHub Pages로 열거나, 파일을 내려받아 브라우저에서 바로 열면 됩니다.

- `전체 보드`: Hero(시계·주간 스트립·날씨·칩 + 포스트잇 메모) → 모닝 브리핑 → 달력·포트폴리오 → 가계부 (오늘 할 일 카드는 중복되지 않도록 `할일·루틴`에만 표시)
- `할일·루틴`: 오늘 카드 → 달력 → 주간·월간·반드시·나중에 4개 섹션
- 날씨는 Open-Meteo(무료, API 키 없음)에서 읽고, 실패하면 마지막 값을 쓰거나 "다시 시도"를 표시합니다. 지역 선택은 `localStorage`(`command_wx_region`)에 저장됩니다.

## `morning-briefing.json` 형식

페이지는 `./morning-briefing.json`을 읽어 브리핑을 갱신합니다. 파일이 없거나 오프라인이면 `index.html`에 내장된 기본값으로 표시됩니다.
**공개 저장소이므로 개인 보유 종목·계좌·일정·이름은 넣지 않습니다.**

```json
{
  "version": 1,
  "date": "2026-11-20",                  // YYYY-MM-DD (필수)
  "weekday": "금",                        // 없으면 date에서 계산
  "label": "한경 임현우 모닝루틴",
  "show": "한경 코리아마켓 《한국경제신문 30분 만에 읽기 | 20261120》",
  "headline": "AI 통행료는 아직 — 코스피 -5.21%",
  "core": "한 문장 핵심 (필수)",
  "terms": [
    { "t": "용어", "d": "쉬운 설명" }
  ],
  "sections": [
    { "k": "flow",    "label": "핵심 흐름",        "items": [ { "h": "소제목", "p": "본문" } ] },
    { "k": "money",   "label": "돈의 이동",        "items": [] },
    { "k": "market",  "label": "시장 연결",        "items": [] },
    { "k": "counter", "label": "반대 시나리오",     "items": [] },
    { "k": "numbers", "label": "앞으로 확인할 숫자", "items": [] },
    { "k": "remember","label": "딱 이것만 기억",     "items": [] }
  ],
  "updated_at": "2026-11-20T16:30:00+09:00"
}
```

- `items`의 각 항목은 `{ "h": 제목, "p": 본문 }` 또는 문자열 하나로도 됩니다.
- `sections`의 순서가 화면 순서이고, 없는 섹션은 표시되지 않습니다.
- 카드에는 각 섹션의 앞부분이 접이식으로, `전체 보기`에는 전부 펼쳐서 표시됩니다.
