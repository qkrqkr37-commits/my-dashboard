# MY · COMMAND BOARD

다크 글래스 톤의 개인 대시보드 — 오늘의 루틴·할 일, 달력 히트맵, 포트폴리오 도넛, 가계부까지 한 화면에 담은 **단일 HTML 파일**입니다.

- 빌드 도구나 서버가 필요 없습니다. `index.html` 하나로 동작합니다.
- 금액·종목·일정은 모두 **예시 데이터**이며, 브라우저를 열 때마다 "오늘"을 기준으로 새로 만들어집니다.
- 기록은 서버로 전송되지 않고 브라우저 `localStorage`에만 저장됩니다.
- 우측 상단 `⋯` 메뉴에서 **JSON으로 백업 / 백업 불러오기 / 예시 데이터로 초기화**를 쓸 수 있습니다. 다른 기기에서 쓰던 기록은 백업 파일을 불러와 그 브라우저에 복원할 수 있습니다.

## 구성

| 영역 | 내용 |
| --- | --- |
| Today | 루틴 5종 진행률 링, 오늘의 할 일 체크리스트 |
| Morning Briefing | 루틴·마감·일정 요약 5건 팝업 |
| Calendar | 월간 히트맵 + 태그 점, 날짜별 체크리스트 |
| Portfolio | 도넛 비중, 종목별 비중·평가금액, 집중도·방어자산 인사이트 |
| Market Pulse | 지수 3종과 스파크라인 (지연 시세 표기) |
| Ledger | 이번 달 수입·지출·예산 게이지, 최근 6개월 막대 차트, 카테고리 비중 |
